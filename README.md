# Баланс — обновлённая версия
Функции: доходы/расходы, категории и даты, бюджеты по категориям, кредиты и платежи, цели накоплений, план зарплаты, регулярные платежи, аналитика за 6 месяцев, настройка валюты и начального баланса, экспорт/импорт резервной копии, офлайн-кэш, миграция старых данных из balance_app_v1.

## Обновление существующей установки
1. Перед обновлением откройте приложение → Ещё → Экспортировать резервную копию. Сохраните JSON в «Файлы».
2. В GitHub откройте репозиторий balans-iphone.
3. Для index.html, manifest.json и sw.js: откройте файл → карандаш Edit → Select All в редакторе → вставьте содержимое одноимённого файла из этого архива → Commit changes. Повторите для каждого.
4. Добавьте новые icon-192.png, icon-512.png: Add file → Upload files → выбрать оба PNG → Commit changes. icon.svg можно добавить тем же способом.
5. Закройте PWA полностью, подождите 30 секунд и откройте снова. Если осталась старая версия — откройте сайт в Safari и обновите страницу.
6. Старые данные должны перенестись автоматически. Если нет — Ещё → Импортировать резервную копию.

Важно: GitHub хранит только код. Финансовые записи остаются локально на конкретном iPhone. Не очищайте данные Safari без копии. Валюта меняет отображение, не конвертирует по курсу. Нет банковской синхронизации и автоматического списания.
